# Avito AntiBot

Решение задачи Avito Data Science Bootcamp по определению автоматизированного трафика по событиям внутри суточного окна наблюдения.

## Структура проекта

```text
.
├── data/
│   ├── train.csv
│   ├── test.csv
│   └── events.csv.gz
├── Avito_AntiBot.ipynb
├── metric.py
├── requirements.txt
└── README.md
```

## Подход

Перед обучением проводится анализ данных и проверка событий внутри разрешённого временного окна:

```text
window_start_ts <= event_ts < window_end_ts
```

Основные группы признаков:

- временное поведение пользователя: интервалы между событиями, интенсивность активности, burst-паттерны;
- навигация и взаимодействие с объявлениями;
- поисковые запросы и глубина просмотра страниц;
- статистики по `item_id` и категориям;
- признаки `user_agent`;
- mouse / pointer признаки;
- геометрия движения указателя: `pointer_extent`, `pointer_area_proxy`, `pointer_axis_imbalance`, расстояние от центра экрана и доля событий около границ;
- статистики exact duplicates.

Для проверки качества используется temporal walk-forward validation, чтобы validation-период всегда находился позже обучающего периода.

## Модели

Финальное решение использует ансамбль из четырёх моделей:

| Модель | Признаки | Вес |
|---|---|---:|
| LightGBM | полный набор | 0.410 |
| CatBoost | полный набор | 0.130 |
| LightGBM | без TOP-5 признаков | 0.335 |
| CatBoost | без тех же TOP-5 признаков | 0.125 |

TOP-5 определяются по `gain importance` LightGBM.

Перед объединением предсказания каждой модели переводятся в ранги, после чего рассчитывается взвешенная сумма.

## Validation

Метрика соревнования:

**Precision @ Recall ≥ 0.70**

Результаты финальной конфигурации на temporal folds:

| Fold | Score |
|---|---:|
| Fold 1 | 0.700000 |
| Fold 2 | 0.794286 |
| Fold 3 | 0.823944 |

## Запуск

Проект тестировался в Google Colab с Python 3.13.15.

Установить зависимости:

```bash
pip install -r requirements.txt
```

После этого открыть:

```text
Avito_AntiBot.ipynb
```

и выполнить ячейки сверху вниз.

Ноутбук ожидает данные в папке `data/`.
